# Auto-Numbering System - Guia Completo

## Visão Geral

O sistema de auto-numeração do TCCFlow oferece uma solução profissional e integrada para numerar automaticamente títulos, seções, parágrafos e criar índices em documentos acadêmicos.

---

## 1. ESTILOS DE TÍTULO (H1-H4)

### Hierarquia Automática
A numeração de títulos segue uma hierarquia inteligente que se atualiza automaticamente:

#### Título 1 (H1)
- Formatação: **1**, **2**, **3**...
- Uso: Títulos principais dos capítulos
- Estilo: Grande, com borda inferior, negrito
- Atalho: `Ctrl+Alt+1`

#### Título 2 (H2)
- Formatação: **1.1**, **1.2**, **2.1**, **2.2**...
- Uso: Seções dentro de capítulos
- Estilo: Médio, com borda esquerda roxa
- Atalho: `Ctrl+Alt+2`

#### Título 3 (H3)
- Formatação: **1.1.1**, **1.1.2**, **1.2.1**...
- Uso: Subseções
- Estilo: Pequeno, com borda esquerda fina
- Atalho: `Ctrl+Alt+3`

#### Título 4 (H4)
- Formatação: **1.1.1.1**, **1.1.1.2**...
- Uso: Detalhes e tópicos menores
- Estilo: Muito pequeno, em itálico
- Atalho: `Ctrl+Alt+4`

### Como Usar Títulos com Auto-Numeração

1. **Método 1 - Atalhos de Teclado (Recomendado)**
   - Clique no texto onde deseja aplicar o estilo
   - Pressione `Ctrl+Alt+1` para Título 1
   - Pressione `Ctrl+Alt+2` para Título 2
   - etc.

2. **Método 2 - Menu da Barra de Ferramentas**
   - Clique no botão "Numeração" (📋) na barra de ferramentas
   - Selecione o nível de título desejado
   - A numeração é aplicada automaticamente

3. **Exemplo Prático**
   ```
   1. Introdução
   1.1. Contextualização
   1.2. Justificativa
   1.3. Objetivos
   1.3.1. Objetivo Geral
   1.3.2. Objetivos Específicos
   2. Revisão Bibliográfica
   2.1. Conceitos Fundamentais
   ```

### Atualização Automática
- A numeração atualiza automaticamente quando você:
  - Adiciona ou remove títulos
  - Altera o nível de um título
  - Modifica a ordem dos títulos

## 2. NUMERAÇÃO DE PARÁGRAFOS

### Estilos de Numeração Disponíveis

#### Numeração Decimal (1, 2, 3)
- Formato: 1., 2., 3., ...
- Uso: Listas de passos, processos
- Espaçamento: Automático

#### Numeração Alfabética (a, b, c)
- Formato: a., b., c., ...
- Uso: Alternativas, opções
- Ordem: Alfabética

#### Numeração Romana (i, ii, iii)
- Formato: i., ii., iii., ...
- Uso: Tópicos formais, referências
- Estilo: Maiúscula ou minúscula

#### Numeração Hierárquica (1.1, 1.2, 2.1)
- Formato: 1.1, 1.2, 2.1, 2.2, ...
- Uso: Listas aninhadas, estruturas complexas
- Vantagem: Mantém relação entre itens

### Como Aplicar Numeração a Parágrafos

1. **Selecione o parágrafo ou crie um novo**
2. **Clique em "Numeração" → "Numeração de Parágrafos"**
3. **Escolha o estilo desejado**

Exemplo:
```
1. Primeiro tópico
2. Segundo tópico
   1.1 Subtópico
   1.2 Outro subtópico
3. Terceiro tópico
```

## 3. MARCADORES

### Tipos de Marcadores

#### Círculos (◦)
- Ícone: Ponto vazio
- Uso: Listas de itens
- Aparência: Elegante e discreta

#### Quadrados (◾)
- Ícone: Quadrado sólido
- Uso: Pontos importantes
- Aparência: Mais marcado

#### Traços (–)
- Ícone: Hífen
- Uso: Alternativas, opções
- Aparência: Minimalista

### Como Usar Marcadores

1. Selecione o texto
2. Clique em "Numeração" → "Marcadores"
3. Escolha o tipo desejado

Exemplo:
```
◦ Primeiro item
◦ Segundo item
◦ Terceiro item
```

## 4. ÍNDICE AUTOMÁTICO (TABLE OF CONTENTS)

### Características

- **Geração Automática**: Baseada em títulos H1-H4
- **Links Navegáveis**: Clique para ir ao título
- **Atualização em Tempo Real**: Reflete mudanças no documento
- **Fechável**: Botão (×) para remover o índice
- **Formatação Profissional**: Estilo integrado com TCCFlow

### Como Gerar o Índice

1. **Clique em "Numeração" → "Gerar Índice"**
2. O índice aparece no início do documento
3. Para remover, clique no botão (×)

### Estrutura do Índice

```
Índice
1. Introdução
   1.1. Contextualização
   1.2. Justificativa
   1.3. Objetivos
      1.3.1. Objetivo Geral
      1.3.2. Objetivos Específicos
2. Revisão Bibliográfica
   2.1. Conceitos Fundamentais
   ...
```

### Dicas

- Crie o índice **após finalizar a estrutura dos títulos**
- O índice se atualiza automaticamente quando você modifica os títulos
- Use as cores para diferenciar níveis de profundidade
- Os links funcionam em leitura e impressão

---

## 5. LIMPEZA DE NUMERAÇÃO

### Remover Toda a Numeração
- Clique em "Numeração" → "Limpar Tudo"
- Remove:
  - Números dos títulos
  - Números dos parágrafos
  - Todos os marcadores
  - O índice (se existir)

### Remover Apenas Numeração de Títulos
- Remova manualmente cada número ou use "Limpar Tudo"

## 8. CARACTERÍSTICAS AVANÇADAS

### Auto-Atualização
- Quando você adiciona um título, a numeração se atualiza automaticamente
- Quando você remove um título, os números se reorganizam
- Quando você altera o nível (H2 para H3), a hierarquia se ajusta

### Estilos Visuais
- **Cores por Nível**: Cada nível de título tem cores específicas
- **Tamanhos Progressivos**: Títulos maiores para níveis principais
- **Bordas Decorativas**: Diferenciam visualmente os níveis
- **Espaçamento**: Automático para melhor legibilidade

### Compatibilidade
- **Impressão**: Todos os números e índices saem corretos
- **PDF**: Exportação mantém a numeração
- **HTML**: Estrutura semântica preservada
- **Navegadores**: Funciona em todos os navegadores modernos

## 9. DICAS E BOAS PRÁTICAS

### Para Melhores Resultados

1. **Planeje a Estrutura**
   - Defina os títulos principais (H1)
   - Crie as seções (H2)
   - Adicione detalhes (H3, H4)

2. **Use Consistentemente**
   - Use sempre o mesmo nível para o mesmo tipo de conteúdo
   - Não pule níveis (ex: H1 direto para H3)

3. **Organize o Índice**
   - Crie o índice quando a estrutura estiver finalizada
   - Revise os títulos antes de usar o índice

4. **Mantenha Simples**
   - Use no máximo H4 para clareza
   - Não misture estilos de numeração no mesmo documento

5. **Para Documentos Longos**
   - Divida em múltiplos capítulos
   - Use H1 para cada capítulo
   - Use Índice para navegação rápida

## 10. SOLUÇÃO DE PROBLEMAS

### A Numeração Não Atualiza
- **Solução**: A numeração atualiza automaticamente. Se não aparecer, clique em outro parágrafo e volte.

### Números Desapareceram
- **Solução**: Desfaça com `Ctrl+Z` ou clique em "Numeração" e reaplique.

### Índice Não Mostra Todos os Títulos
- **Solução**: Certifique-se que todos os títulos estão usando H1-H4 (não H5 ou H6).

### Numeração em Ordem Errada
- **Solução**: Mova os títulos para a ordem correta. A numeração se ajustará automaticamente.

### Caracteres Especiais Aparecem Errados
- **Solução**: Verifique a codificação do documento (deve ser UTF-8).

## 11. INTEGRAÇÕES DISPONÍVEIS

- Clique em "Download HTML" para salvar com numeração

### Exportar

- **PDF**: Gera com table of contents automático
