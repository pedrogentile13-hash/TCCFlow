1. CRITICAL FEATURE: AUTOMATIC CITATION SYSTEM
================================================================================

OVERVIEW:
The citation system is seamlessly integrated and intuitive. Users can:
1. Select text in the editor
2. Press Ctrl+Shift+C to insert citation
3. A blue superscript number appears instantly (e.g., ¹)
4. A footnote is AUTOMATICALLY created at the bottom
5. User types the citation reference (author, date, source, etc)
6. Numbers auto-update if citations are added/removed

FILES INVOLVED:
- /js/citations.js (294 lines) - CORE CITATION ENGINE
- /js/rich-text-editor.js (UPDATED) - Keyboard integration
