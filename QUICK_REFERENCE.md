# Auto-Numbering System - Quick Reference

## 🎯 3-Second Start

1. **Select text** or **create new line**
2. **Press Ctrl+Alt+1** (for Title 1) or use **Numeração menu**
3. **Type your text** → Numbers appear automatically!

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl+Alt+1` | Title 1 - Main heading |
| `Ctrl+Alt+2` | Title 2 - Subheading |
| `Ctrl+Alt+3` | Title 3 - Sub-subheading |
| `Ctrl+Alt+4` | Title 4 - Detail level |

---

## 📋 Numbering Styles (Via Menu)

### Titles
- **1, 2, 3** → Heading 1
- **1.1, 1.2, 2.1** → Heading 2
- **1.1.1, 1.2.1** → Heading 3
- **1.1.1.1** → Heading 4

### Paragraph Numbering
- **1., 2., 3.** → Decimal
- **a., b., c.** → Alphabetic
- **i., ii., iii.** → Roman
- **1.1, 1.2, 2.1** → Hierarchical

### Bullets
- **◦** → Circles
- **◾** → Squares
- **–** → Dashes

### Special
- **Gerar Índice** → Auto table of contents
- **Limpar Tudo** → Remove all numbering

## 🎨 Visual Styles

**H1** - Large, bold, bottom border
**H2** - Medium, left border (violet)
**H3** - Small, thin left border
**H4** - Italic, gray, subtle

## 💡 Tips

✓ Use keyboard shortcuts for speed
✓ Plan titles before numbering
✓ Create index after structure is done
✓ Number levels logically (no skipping)
✓ Use consistent style throughout
✓ Index updates automatically

---

## ⚠️ Common Issues

| Problem | Solution |
|---------|----------|
| Numbers not updating | Click elsewhere, then back |
| Numbers disappeared | Undo (Ctrl+Z) |
| Index missing headings | Use H1-H4, not H5-H6 |
| Wrong order | Move headings, numbers adjust |

---
