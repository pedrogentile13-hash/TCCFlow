1 Criando a Conta no Mercado Pago

  1. Acesse mercadopago.com.br/developers
  2. Crie uma conta ou faca login com sua conta Mercado Pago existente
  3. Acesse o Dashboard do Desenvolvedor
  4. Clique em "Criar aplicacao"
  5. Preencha:
    • Nome: TCCFlow
    • Modelo de integracao: Checkout API
    • Produto: Checkout API
  6. Salve a aplicacao
Dica: Use o modo Sandbox para testes antes de ir para producao.

2 Obtendo as Credenciais (API Keys)

No dashboard da sua aplicacao, voce encontrara duas credenciais principais:

Public Key

Usada no frontend (SDK JavaScript) para tokenizar cartoes. Segura para expor no browser.

APP_USR-xxxxxxxx-xxxx-xxxx

Access Token

Usada no backend (Netlify Functions). NUNCA exponha no frontend!

APP_USR-xxxxxxxx-xxxx-xxxx

Configuracao no Netlify:

Adicione as credenciais como variaveis de ambiente no Netlify:

# Netlify > Site Settings > Environment Variables
MP_ACCESS_TOKEN=APP_USR-seu-access-token-aqui
MP_PUBLIC_KEY=APP_USR-sua-public-key-aqui

3 Pagamento via PIX

O PIX e o metodo mais rapido e barato. O fluxo e:

1. Criar pagamento 2. Receber QR Code 3. Usuario paga 4. Webhook confirma

Netlify Function - Criar Pagamento PIX:

// netlify/functions/create-pix.js
const fetch = require('node-fetch');

exports.handler = async (event) => {
    if (event.httpMethod !== 'POST') {
        return { statusCode: 405, body: 'Method Not Allowed' };
    }

    const { amount, email, description, userId } = JSON.parse(event.body);

    const response = await fetch('https://api.mercadopago.com/v1/payments', {
        method: 'POST',
        headers: {
            'Authorization': `Bearer ${process.env.MP_ACCESS_TOKEN}`,
            'Content-Type': 'application/json',
            'X-Idempotency-Key': `${userId}-${Date.now()}`
        },
        body: JSON.stringify({
            transaction_amount: amount,
            description: description || 'TCCFlow Pro',
            payment_method_id: 'pix',
            payer: {
                email: email
            },
            metadata: {
                user_id: userId
            }
        })
    });

    const data = await response.json();

    if (data.id) {
        return {
            statusCode: 200,
            body: JSON.stringify({
                id: data.id,
                qr_code: data.point_of_interaction
                    .transaction_data.qr_code,
                qr_code_base64: data.point_of_interaction
                    .transaction_data.qr_code_base64,
                ticket_url: data.point_of_interaction
                    .transaction_data.ticket_url
            })
        };
    }

    return {
        statusCode: 400,
        body: JSON.stringify({ error: data.message })
    };
};

Frontend - Exibir QR Code PIX:

// No planos.html ou checkout page
async function payWithPix(seats) {
    const total = 97 + (seats > 1 ? (seats - 1) * 30 : 0);
    const user = auth.currentUser;

    const response = await fetch('/.netlify/functions/create-pix', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            amount: total,
            email: user.email,
            description: `TCCFlow Pro - ${seats} assento(s)`,
            userId: user.uid
        })
    });

    const data = await response.json();

    if (data.qr_code_base64) {
        // Exibir QR Code na tela
        document.getElementById('pixQrCode').src =
            `data:image/png;base64,${data.qr_code_base64}`;
        document.getElementById('pixCopyPaste').textContent =
            data.qr_code;
        document.getElementById('pixModal').classList.remove('hidden');
    }
}
Nota: O QR Code PIX expira em 30 minutos por padrao. O pagamento e confirmado instantaneamente via webhook.

4 Pagamento via Cartao de Credito (Parcelado)

Passo 1 - Adicionar SDK do Mercado Pago no HTML:

<!-- Adicionar no <head> do planos.html -->
<script src="https://sdk.mercadopago.com/js/v2"></script>

Passo 2 - Formulario de cartao com tokenizacao:

// Inicializar o SDK com sua Public Key
const mp = new MercadoPago('SUA_PUBLIC_KEY');

const cardForm = mp.cardForm({
    amount: '97',
    iframe: true,
    form: {
        id: 'form-checkout',
        cardNumber: { id: 'form-checkout__cardNumber' },
        expirationDate: { id: 'form-checkout__expirationDate' },
        securityCode: { id: 'form-checkout__securityCode' },
        cardholderName: { id: 'form-checkout__cardholderName' },
        issuer: { id: 'form-checkout__issuer' },
        installments: { id: 'form-checkout__installments' },
        identificationType: { id: 'form-checkout__identificationType' },
        identificationNumber: { id: 'form-checkout__identificationNumber' },
        cardholderEmail: { id: 'form-checkout__cardholderEmail' }
    },
    callbacks: {
        onFormMounted: (error) => {
            if (error) console.warn('Form mount error:', error);
        },
        onSubmit: async (event) => {
            event.preventDefault();
            const formData = cardForm.getCardFormData();

            // Enviar token para o backend
            const response = await fetch(
                '/.netlify/functions/process-payment', {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({
                    token: formData.token,
                    issuer_id: formData.issuerId,
                    payment_method_id: formData.paymentMethodId,
                    transaction_amount: Number(formData.amount),
                    installments: Number(formData.installments),
                    payer: {
                        email: formData.cardholderEmail,
                        identification: {
                            type: formData.identificationType,
                            number: formData.identificationNumber
                        }
                    },
                    userId: auth.currentUser.uid
                })
            });

            const result = await response.json();
            if (result.status === 'approved') {
                alert('Pagamento aprovado!');
                window.location.href = 'dashboard.html';
            }
        }
    }
});

Passo 3 - Netlify Function para processar pagamento:

// netlify/functions/process-payment.js
const fetch = require('node-fetch');

exports.handler = async (event) => {
    if (event.httpMethod !== 'POST') {
        return { statusCode: 405, body: 'Method Not Allowed' };
    }

    const body = JSON.parse(event.body);

    // Validar preco no servidor (seguranca)
    const BASE_PRICE = 97;
    const SEAT_PRICE = 30;
    const seats = body.seats || 1;
    const expectedAmount = BASE_PRICE + (seats > 1
        ? (seats - 1) * SEAT_PRICE : 0);

    if (body.transaction_amount !== expectedAmount) {
        return {
            statusCode: 400,
            body: JSON.stringify({ error: 'Valor invalido' })
        };
    }

    const response = await fetch(
        'https://api.mercadopago.com/v1/payments', {
        method: 'POST',
        headers: {
            'Authorization':
                `Bearer ${process.env.MP_ACCESS_TOKEN}`,
            'Content-Type': 'application/json',
            'X-Idempotency-Key': `${body.userId}-${Date.now()}`
        },
        body: JSON.stringify({
            token: body.token,
            issuer_id: body.issuer_id,
            payment_method_id: body.payment_method_id,
            transaction_amount: body.transaction_amount,
            installments: body.installments,
            description: `TCCFlow Pro - ${seats} assento(s)`,
            payer: body.payer,
            metadata: {
                user_id: body.userId,
                seats: seats
            }
        })
    });

    const data = await response.json();

    return {
        statusCode: 200,
        body: JSON.stringify({
            status: data.status,
            status_detail: data.status_detail,
            id: data.id
        })
    };
};
Parcelamento: O campo installments do CardForm automaticamente mostra as opcoes de parcelamento disponiveis (1x a 12x). O Mercado Pago calcula os juros automaticamente.

5 Integracao com o TCCFlow (Netlify Functions)

Para integrar o Mercado Pago no TCCFlow, voce precisa:

1

Instalar dependencia do Mercado Pago

npm install mercadopago
2

Criar as Netlify Functions

Crie os arquivos conforme mostrado nas secoes 3 e 4:

  • netlify/functions/create-pix.js - Pagamento PIX
  • netlify/functions/process-payment.js - Cartao de credito
  • netlify/functions/webhook-mp.js - Webhook (secao 6)
  • netlify/functions/create-preference.js - Checkout Pro (recomendado)
3

Configurar variaveis de ambiente no Netlify

MP_ACCESS_TOKEN=APP_USR-xxx
MP_PUBLIC_KEY=APP_USR-xxx

Checkout Pro (metodo usado no TCCFlow)

O Checkout Pro redireciona o usuario para a pagina do Mercado Pago. Aceita PIX + cartao automaticamente:

// netlify/functions/create-preference.js
const { MercadoPagoConfig, Preference } = require('mercadopago');

const client = new MercadoPagoConfig({
    accessToken: process.env.MP_ACCESS_TOKEN
});

exports.handler = async (event) => {
    const { seats, userId, userEmail } = JSON.parse(event.body);
    const total = 97 + (seats > 1 ? (seats - 1) * 30 : 0);

    const preference = new Preference(client);
    const result = await preference.create({
        body: {
            items: [{
                title: `TCCFlow Pro - ${seats} assento(s)`,
                quantity: 1,
                unit_price: total,
                currency_id: 'BRL'
            }],
            payer: { email: userEmail },
            back_urls: {
                success: 'https://tccflow.com.br/pages/dashboard.html',
                failure: 'https://tccflow.com.br/pages/planos.html',
                pending: 'https://tccflow.com.br/pages/planos.html'
            },
            auto_return: 'approved',
            notification_url:
                'https://tccflow.com.br/.netlify/functions/webhook-mp',
            metadata: { user_id: userId, seats: seats }
        }
    });

    return {
        statusCode: 200,
        body: JSON.stringify({ url: result.init_point })
    };
};

6 Webhook - Confirmacao de Pagamento

O webhook recebe notificacoes do Mercado Pago quando um pagamento e aprovado e atualiza o Firestore:

// netlify/functions/webhook-mp.js
const fetch = require('node-fetch');
const admin = require('firebase-admin');

// Inicializar Firebase Admin
if (!admin.apps.length) {
    admin.initializeApp({
        credential: admin.credential.cert(
            JSON.parse(process.env.FIREBASE_SERVICE_ACCOUNT)
        )
    });
}
const db = admin.firestore();

exports.handler = async (event) => {
    if (event.httpMethod !== 'POST') {
        return { statusCode: 200, body: 'OK' };
    }

    const body = JSON.parse(event.body);

    // Mercado Pago envia o tipo de notificacao
    if (body.type === 'payment') {
        const paymentId = body.data.id;

        // Buscar detalhes do pagamento
        const response = await fetch(
            `https://api.mercadopago.com/v1/payments/${paymentId}`,
            {
                headers: {
                    'Authorization':
                        `Bearer ${process.env.MP_ACCESS_TOKEN}`
                }
            }
        );
        const payment = await response.json();

        if (payment.status === 'approved') {
            const userId = payment.metadata.user_id;
            const seats = payment.metadata.seats || 1;

            // Atualizar Firestore
            await db.collection('subscriptions')
                .doc(userId).set({
                    status: 'active',
                    plan: 'pro',
                    seats: seats,
                    paymentId: payment.id,
                    paymentMethod: payment.payment_method_id,
                    userId: userId,
                    userEmail: payment.payer.email,
                    activatedAt: admin.firestore
                        .FieldValue.serverTimestamp()
                }, { merge: true });
        }
    }

    return { statusCode: 200, body: 'OK' };
};

Configurar URL do Webhook no Mercado Pago:

  1. Acesse o Dashboard do Desenvolvedor
  2. Va em Webhooks
  3. Adicione a URL: https://tccflow.com.br/.netlify/functions/webhook-mp
  4. Selecione o evento: Payments
  5. Salve
Seguranca: Em producao, sempre verifique a assinatura do webhook usando o x-signature header e o secret fornecido pelo Mercado Pago para evitar fraudes.

# Aprovar pagamento PIX de teste via API
curl -X PUT \
  "https://api.mercadopago.com/v1/payments/{PAYMENT_ID}" \
  -H "Authorization: Bearer TEST-ACCESS-TOKEN" \
  -H "Content-Type: application/json" \
