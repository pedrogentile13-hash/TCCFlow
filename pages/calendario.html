Como configurar

  1. Acesse o Google Cloud Console
  2. Crie um projeto e ative a Google Calendar API
  3. Configure a tela de consentimento OAuth
  4. Crie credenciais OAuth 2.0 (tipo: Aplicativo Web)
  5. Adicione o domínio do TCCFlow nas origens autorizadas
  6. Insira o Client ID no código (variável GOOGLE_CLIENT_ID)
